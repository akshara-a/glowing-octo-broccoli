# Weather Dashboard

A simple weather dashboard built using HTML, CSS and JavaScript.

The application uses the OpenWeatherMap Current Weather API
to display current weather information for a city.

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- OpenWeatherMap API

## Features

- Search weather by city name
- Display city and country
- Display temperature
- Display weather condition
- Display weather description
- Display humidity
- Display wind speed
- Loading message
- Error handling
- Enter key search
- API key authentication

## API Used

OpenWeatherMap Current Weather API.

API endpoint:

https://api.openweathermap.org/data/2.5/weather
