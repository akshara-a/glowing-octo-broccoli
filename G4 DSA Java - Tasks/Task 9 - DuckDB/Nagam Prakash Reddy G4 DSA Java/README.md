# DuckDB Assignment Using Parquet

## Overview

This project demonstrates how to use DuckDB to query, filter,
aggregate, and export Parquet data using SQL.

The project uses employee information stored in a Parquet file
and performs various SQL operations using DuckDB.

---

## Technologies Used

- Python
- Pandas
- DuckDB
- PyArrow
- Parquet
- SQL
