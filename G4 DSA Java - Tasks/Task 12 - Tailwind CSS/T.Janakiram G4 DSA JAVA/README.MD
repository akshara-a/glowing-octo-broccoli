# Responsive Product Landing Page (Tailwind CSS)

A responsive product landing page built using HTML5 and Tailwind CSS utility classes.

## Features & Sections

- **Navigation Bar**: Responsive header with desktop links, mobile hamburger drawer, and theme toggling.
- **Hero Section**: Value proposition with call-to-action buttons and a responsive dashboard illustration.
- **Features Grid**: 3-column responsive grid layout using Tailwind `flex`, `grid`, and hover elevation classes.
- **Pricing Cards**: 3 tier pricing layout with a highlighted "Most Popular" card and distinct CTA buttons.
- **Testimonials (Bonus)**: Customer quote cards with attribution.
- **Contact Form**: Responsive, styled input fields with focus rings and hover states.
- **Footer**: Copyright, navigation links, and social links.
- **Dark Mode (Bonus)**: Theme switcher storing preferences in `localStorage`.

## Technologies Used

- **HTML5**
- **Tailwind CSS (CDN)**
- **JavaScript (Vanilla)**

## Responsive Breakpoints Used

- `sm:` (640px)
- `md:` (768px)
- `lg:` (1024px)
