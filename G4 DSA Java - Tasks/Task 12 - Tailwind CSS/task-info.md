# Assignment: Build a Responsive Website Using Tailwind CSS

## Objective

The purpose of this assignment is to practice **Tailwind CSS utility classes** and learn how to create a modern, responsive webpage without writing much custom CSS.

## Task

Create a **responsive product landing page** using **HTML and Tailwind CSS**.

Your webpage should contain the following sections:

### 1. Navigation Bar

Include:

* Website logo/name
* Home
* Products
* About
* Contact
* Login or Sign Up button

The navigation bar should adapt properly to smaller screens.

### 2. Hero Section

Include:

* Main heading
* Short description
* Call-to-action button such as **Get Started** or **Shop Now**
* Product or website image

Use Tailwind classes for spacing, typography, alignment, and responsive layout.

### 3. Features Section

Create at least **3 feature cards**.

Each card should contain:

* Icon or image
* Feature title
* Short description

Use Tailwind utilities such as:

* `flex`
* `grid`
* `p-*`
* `m-*`
* `rounded-*`
* `shadow-*`
* `hover:*`

### 4. Product/Pricing Section

Create at least **3 product or pricing cards**.

Each card should display:

* Product/plan name
* Price
* Description or features
* Button

Add a hover effect to the cards or buttons.

### 5. Contact Section

Create a contact form containing:

* Name
* Email
* Message
* Submit button

Style all form elements using Tailwind CSS.

### 6. Footer

Include:

* Website name
* Copyright text
* Social media links
* Privacy Policy or Terms link

## Responsive Design Requirements

Your webpage should work correctly on:

* Mobile devices
* Tablets
* Desktop screens

Use Tailwind responsive prefixes such as:

`sm:`, `md:`, `lg:`, and `xl:`

Example:

```html
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3">
```

## Tailwind CSS Concepts to Demonstrate

Your project should demonstrate the use of:

* Typography utilities
* Colors and backgrounds
* Margin and padding
* Flexbox
* CSS Grid
* Borders and rounded corners
* Shadows
* Hover states
* Responsive utilities
* Width and height utilities

## Bonus Tasks

For additional marks:

1. Add **dark mode**.
2. Add animations or transitions.
3. Create a mobile navigation menu.
4. Add a testimonial section.
5. Use reusable Tailwind component styles effectively.
