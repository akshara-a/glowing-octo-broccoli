# NovaTech Product Landing Page

## Project Description

NovaTech is a responsive product landing page created using HTML,
Tailwind CSS, and JavaScript.

The project demonstrates how Tailwind CSS utility classes can be used
to create a modern responsive website without relying heavily on
custom CSS.

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Responsive Design
- CSS Grid
- Flexbox

## Website Sections

1. Navigation Bar
2. Hero Section
3. Features Section
4. About Section
5. Pricing Section
6. Testimonials Section
7. Contact Form
8. Footer

## Bonus Features

- Dark mode
- Mobile navigation menu
- Hover effects
- CSS animations
- Smooth scrolling
- Responsive layouts
- Interactive contact form

## Responsive Design

The website uses Tailwind responsive prefixes including:

- `sm:`
- `md:`
- `lg:`
- `xl:`

The layout adapts to:

- Mobile phones
- Tablets
- Desktop computers

## How to Run

1. Create a folder called `novatech`.
2. Add `index.html`.
3. Add `script.js`.
4. Add this `README.md`.
5. Open `index.html` in a web browser.

Internet access is required because Tailwind CSS is loaded through
the Tailwind CDN.
