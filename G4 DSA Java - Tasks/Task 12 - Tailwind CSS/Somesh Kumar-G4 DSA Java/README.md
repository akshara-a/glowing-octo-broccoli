# NovaPods - Responsive Product Landing Page

## Overview

NovaPods is a responsive product landing page created using HTML and Tailwind CSS.

The project demonstrates how Tailwind CSS utility classes can be used to create a modern and responsive website with minimal custom CSS.

## Features

- Responsive navigation bar
- Mobile navigation menu
- Hero section
- Product features section
- Pricing section
- About section
- Customer testimonials
- Contact form
- Responsive footer
- Dark mode
- Hover effects
- Smooth transitions

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

## Tailwind CSS Concepts Demonstrated

- Typography utilities
- Colors and backgrounds
- Margin and padding
- Flexbox
- CSS Grid
- Borders
- Rounded corners
- Shadows
- Hover states
- Responsive utilities
- Width and height utilities
- Dark mode
- Transitions

## Responsive Design

The website is designed to work on:

- Mobile devices
- Tablets
- Desktop screens

Tailwind responsive prefixes such as `sm:`, `md:`, and `lg:` are used throughout the project.

## How to Run

Open `index.html` in a web browser.

An internet connection is required because Tailwind CSS is loaded using the Tailwind CDN.
